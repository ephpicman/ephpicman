# EphpicMan

My personal knowledge base and engineering workspace.

This repository contains technical notes, practical guides, reusable code examples, experiments, benchmarks, and small development tools collected throughout my software engineering work.

## Contents

- [Design Patterns in PHP](tutorials/design-patterns/README.md) — Test-driven implementations of the 23 classic Gang of Four design patterns, with PHPUnit tests.
- `benchmarks/` — Performance benchmarks and technical comparisons.
- `tests/` — Isolated experiments and test cases.
- `snippets/` — Reusable code snippets and examples.
- `notes/` — Technical notes, concepts, and research.
- `guides/` — Practical guides and software documentation.
- `tools/` — Small development utilities and scripts.
- `gists/` — Curated and archived code gists.

This repository is a personal reference library, not a production package or application.

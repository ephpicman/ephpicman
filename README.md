# EphpicMan

My personal knowledge base and engineering workspace.

This repository contains technical notes, practical guides, reusable code snippets, experiments, benchmarks, and development tools collected throughout my software engineering journey.

## Contents

- `lab/` — Practical experiments, implementations, and technical learning projects.
  - [Design Patterns](lab/design-patterns/) — PHP implementations and PHPUnit tests for the 23 classic Gang of Four patterns.
- `benchmarks/` — Performance benchmarks and technical comparisons.
- `tests/` — Isolated experiments and test cases.
- `snippets/` — Reusable code snippets and examples.
- `notes/` — Technical notes, concepts, and research.
- `guides/` — Practical guides and software documentation.
- `tools/` — Small development utilities and scripts.
- `gists/` — Curated and archived code gists.

This repository is primarily a personal reference library, not a production package or application.
